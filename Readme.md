# Six Cities

Сервис для поиска жилья для путешествий

## Стек

- HTML
- CSS
- TypeScript
- React
- Redux
- Vite

## Возможности

- авторизация;
- просмотр предложений по аренде жилья в шести городах;
- сортировка предложений;
- просмотр подробной инфомации о предложении;
- отображение предложений на интерактивной карте;
- добавление предложений в избранное;
- просмотр отзывов к предложению;
- отправка отзывов авторизованными пользователями;

## Запуск

npm install
npm start
